# Liminality
Liminality is a modern web-based chat application designed to enable seamless, secure, and real-time communication between users. The name Liminality symbolizes a threshold representing the bridge between people. The project aims to create a responsive and interactive chat platform where users can exchange text messages and media files securely. Built using the MERN stack, along with modern tools for state management, security, and cloud integration, Liminality provides a scalable and efficient messaging experience.

# System Architecture

## Backend
- **Node.js**
- **Express.js**
- **MongoDB Atlas**
- **JWT Authentication**
- **Bcrypt.js (Password Hashing)**
- **Arcjet (Security & Rate Limiting)**
- **Dotenv (Environment Variables)**
- **Cookie Parser**
- **CORS**
- **Socket.io (Real-time Communication)**

## Frontend
- **React**
- **Tailwind CSS**
- **Zustand (State Management)**
- **Axios (API Requests)**
- **React Hot Toast (Notifications)**
- **Cloudinary (Media Storage)**

The frontend interacts with the backend via REST APIs, which handle authentication, message storage, and media management.
